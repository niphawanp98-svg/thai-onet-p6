# ศูนย์การเรียนรู้สำนวน สุภาษิต คำพังเพย ป.6 (ติวเข้ม O-NET 2569)
### โรงเรียนราษฎร์บำรุง

เว็บไซต์สื่อการเรียนการสอนดิจิทัลและชุดเตรียมความพร้อมทดสอบระดับชาติขั้นพื้นฐาน (O-NET) กลุ่มสาระการเรียนรู้ภาษาไทย ชั้นประถมศึกษาปีที่ 6 ตามมาตรฐานและตัวชี้วัด **ท 4.1 ป.6/2**

---

## 🌟 ฟังก์ชันหลักทั้ง 4 เมนู

### 1. 📖 สรุปบทเรียน & ทริค O-NET (Learn)
* **จำแนกชัดเจน 3 รูปแบบ:** สรุปความแตกต่างของ **สำนวน**, **สุภาษิต** และ **คำพังเพย**
* **ตารางสูตรลัดตัดช้อยส์ O-NET:** เจตนาของประโยค, คีย์เวิร์ดช่วยจำ (เช่น อย่า, จง, ให้), และความรู้สึกที่พบ
* **ปุ่มกดฟังเสียงสรุป:** รองรับการสังเคราะห์เสียงอ่านออกเสียงภาษาไทย

### 2. 🔍 คลังสำนวนภาพ (Dictionary & Explorer)
* **รวบรวม 36 สำนวนยอดฮิต** ตรงตามหลักสูตร ป.6 และสถิติข้อสอบ O-NET ย้อนหลัง
* **ระบบค้นหาและตัวกรอง:** ค้นหาคำศัพท์/ความหมาย และกรองตามประเภท หรือหมวดหมู่ (สัตว์, ธรรมชาติ, ของใช้, ร่างกาย, พฤติกรรม)
* **หน้าต่างเจาะลึก (Modal):** แสดงความหมาย, ที่มา/เกร็ดความรู้ทางประวัติศาสตร์และวรรณคดี, และตัวอย่างประโยคในชีวิตจริง

### 3. 🎮 มินิเกมฝึกสมอง 3 รูปแบบ (Interactive Games)
* **เกมที่ ๑ "แยกให้ถูก กล่องไหนเอ่ย?":** อ่านการ์ดสำนวนแล้วเลือกลงกล่อง สำนวน / สุภาษิต / คำพังเพย พร้อมเฉลยเหตุผลทันที
* **เกมที่ ๒ "ถอดรหัสภาพปริศนา":** ดูภาพ Emoji และคำใบ้ เพื่อทายสำนวนที่ตรงกัน
* **เกมที่ ๓ "ต่อสำนวนให้สมบูรณ์":** เติมคำที่หายไปในสำนวนให้ถูกต้องครบถ้วน

### 4. 📝 คลังข้อสอบ O-NET + เกียรติบัตรออนไลน์ (Exam & Certificate)
* **ชุดข้อสอบ 15 ข้อ** สไตล์ O-NET ย้อนหลังและข้อสอบวิเคราะห์ตามแนว สทศ.
* **ระบบจับเวลาเสมือนจริง 15 นาที** และแถบวัดความคืบหน้า
* **ระบบเฉลยละเอียดและวิเคราะห์ข้อสอบ:** อธิบายทุกข้อว่าทำไมถึงถูก และข้ออื่นผิดเพราะอะไร
* **เกียรติบัตรออนไลน์ (E-Certificate):** เมื่อได้คะแนนตั้งแต่ **70% ขึ้นไป (11 ข้อ)** จะได้รับเกียรติบัตรลวดลายสวยงาม พร้อมระบุชื่อนักเรียน, โรงเรียนราษฎร์บำรุง, คะแนน และวันที่ สามารถกด **"สั่งพิมพ์ / บันทึก PDF"** ได้ทันที

## 🚀 วิธีเปิดใช้งาน
1. ดับเบิลคลิกเปิดไฟล์ `index.html` ใน Google Chrome, Microsoft Edge, Safari หรือเบราว์เซอร์ใดก็ได้
2. สามารถเปิดใช้งานได้ทั้งบน **คอมพิวเตอร์**, **Smart TV / จอโปรเจกเตอร์หน้าห้องเรียน**, **แท็บเล็ต/iPad** และ **โทรศัพท์มือถือ**
